# Main Landing Page

This is the main landing page for `username.github.io`.

## Setup

1. Create a new GitHub repository named `yourusername.github.io`
2. Copy all files from this `main-page` directory to the new repository
3. Install dependencies: `npm install`
4. Deploy: `npm run deploy`

## Structure

- Main page at: `https://yourusername.github.io/`
- Portfolio at: `https://yourusername.github.io/portfolio/`
